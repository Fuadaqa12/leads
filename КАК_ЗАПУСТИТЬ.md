# Поиск клиентов: как запустить

Скрипт ищет в Google Картах бизнесы без сайта (или где вместо сайта только Instagram/Facebook) и делает таблицу с готовыми сообщениями на AZ и RU. В HTML-файле у каждого бизнеса есть кнопка WhatsApp: нажал, проверил текст, отправил сам.

Работает через официальный Google Places API, поэтому никаких банов и капч.

## 1. Получить ключ Google (один раз, 10 минут)

1. Зайди на https://console.cloud.google.com и войди через Gmail.
2. Сверху нажми «Select a project» → «New project», назови как хочешь, например `leads`.
3. Слева меню → **Billing** → привяжи карту. Без карты Google не даёт ключ, но деньги не списываются, пока не выйдешь за бесплатный лимит (примерно 1000 запросов в месяц на этот тип поиска, это до 20 000 бизнесов).
4. Меню → **APIs & Services → Library** → найди **Places API (New)** → **Enable**.
5. **APIs & Services → Credentials → Create credentials → API key**. Скопируй ключ.
6. Нажми на ключ → **API restrictions → Restrict key** → выбери только **Places API (New)** → Save. Так ключ бесполезен, если его украдут.
7. Для спокойствия: **APIs & Services → Places API (New) → Quotas** → поставь лимит, например 50 запросов в день. И в **Billing → Budgets & alerts** сделай бюджет $1 с уведомлением на почту.

## 2. Вставить ключ

Открой файл `api_key.txt` в этой папке, сотри текст и вставь ключ одной строкой. Сохрани.
Никому этот файл не отправляй.

## 3. Установить Python (если нет)

Скачай с https://www.python.org/downloads/ . На Windows при установке поставь галочку **«Add Python to PATH»**. Больше ничего ставить не нужно.

## 4. Запустить

Открой папку со скриптом, в адресной строке проводника напиши `cmd` и нажми Enter. Потом:

```
python find_clients.py
```

Через минуту в папке `results` появятся два файла:
- `leads_....html` — открой в браузере, там кнопки WhatsApp и карта;
- `leads_....csv` — то же самое для Excel, колонку «Статус» заполняй сам (написал / ответил / клиент / отказ).

Сверху списка те, у кого мобильный номер (есть WhatsApp) и больше отзывов: это живой бизнес, ему проще продать.

## Полезные варианты

```
python find_clients.py --city "Sumqayıt"
python find_clients.py --city "Gəncə" --lang az
python find_clients.py --categories "барбершоп,автосервис,стоматология" --pages 3
python find_clients.py --city "Istanbul" --lang en --all
```

- `--pages 3` — до 60 мест на категорию вместо 20 (в 3 раза больше запросов).
- `--all` — показывать и тех, у кого сайт есть (для клиентов, кому нужен редизайн).
- Обычный запуск = 20 категорий × 1 страница = 20 запросов. В месяц бесплатно примерно 1000, то есть можно спокойно запускать каждый день.

## Как писать, чтобы не забанили

- Не больше 20–30 новым людям в день с одного номера. Лучше отдельный номер под работу и WhatsApp Business.
- Скрипт специально ничего не отправляет сам: массовая авторассылка = бан номера.
- Сильнее всего работает, когда сразу кидаешь ссылку на готовый демо-сайт под этот бизнес. Можно сначала отправить сообщение из таблицы, а тем, кто ответил «покажи», сделать демо.

## Kwork и Upwork

Ботом парсить заказы там нельзя: это против их правил, аккаунт заблокируют. Что можно сделать законно и почти так же быстро:
- **Kwork:** раздел «Биржа» → фильтр «Разработка и IT → Сайты» → включи уведомления о новых проектах в приложении. Плюс выложи свой кворк «Сайт для малого бизнеса под ключ».
- **Upwork:** сохрани поиск (Saved search) по `landing page`, `small business website`, `wordpress website` и включи уведомления на почту и в приложении. Отвечать лучше в первые 30 минут.

# Автопилот: клиенты ищутся сами каждый день

`autopilot.py` при каждом запуске:
1. Ищет следующие 10 категорий (по кругу, чтобы не тратить лимит). Кого уже находил, второй раз не берёт.
2. Каждому новому бизнесу делает лёгкий демо-сайт с его названием, рейтингом, телефоном, кнопкой WhatsApp и картой. Сверху плашка «Это лёгкая демо-версия, можем сделать полноценный сайт». Язык AZ/RU переключается.
3. Обновляет страницу-очередь: бизнес, ссылка на его демо и кнопка WhatsApp, где уже вставлен текст со ссылкой на демо. Отметки «написал» ставятся сами при нажатии.

Пример демо-сайта и очереди: папка `primer/`.

## Вариант А (лучший): всё работает в облаке, комп не нужен

Бесплатно через GitHub. Каждый день в 09:00 по Баку GitHub сам запускает поиск, создаёт демо-сайты и выкладывает их в интернет. Ты открываешь очередь с телефона и жмёшь кнопки.

1. Зарегистрируйся на https://github.com и создай репозиторий, например `leads` (Public, иначе бесплатный хостинг не работает).
2. Загрузи туда все файлы из этой папки, кроме `api_key.txt` (кнопка «Add file → Upload files», папку `.github` тоже).
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Name: `GOOGLE_MAPS_API_KEY`, Value: твой ключ.
4. **Settings → Pages → Branch: main, папка /docs → Save.**
5. **Actions → «Поиск клиентов каждый день» → Run workflow**, чтобы запустить первый раз сразу.
6. Через пару минут очередь будет тут: `https://ТВОЙ_НИК.github.io/leads/` + имя файла из `config.json` → `queue_file`. Сохрани ссылку в закладки на телефоне. Имя файла случайное, чтобы очередь никто не нашёл.

## Вариант Б: на своём компе

Дважды кликни `run_autopilot.bat`. Очередь появится в `docs/`. Но демо-сайты при этом только у тебя на компе, клиенту ссылку не отправишь, пока не выложишь папку `docs` в интернет (проще всего вариант А).

## Настройки (`config.json`)

- `cities` — города, например `["Bakı", "Sumqayıt", "Gəncə"]`
- `categories` — что искать
- `searches_per_run` — сколько поисков за запуск (10 в день ≈ 300 в месяц, бесплатно)
- `price` — цена в сообщении

## Почему отправка не автоматическая

WhatsApp банит номера, которые сами пишут незнакомым. Официальный WhatsApp Business API тоже запрещает первым писать тем, кто не дал согласие. Поэтому скрипт делает всё до последнего шага, а ты жмёшь одну кнопку «отправить». 25 человек это минут 10 в день.
Новый номер под это купить стоит: WhatsApp Business, фото профиля, название вроде «Saytlar 50 AZN». Не пиши больше 20–30 новым в день, первую неделю 10–15.

## Демо-сайты: дизайн по типу бизнеса

Каждому новому клиенту автопилот делает демо-сайт под его тип (кафе, барбершоп, салон, автосервис,
мойка, стоматология, ветклиника, фитнес, пекарня, цветы, химчистка, ремонт телефонов, мебель, фото,
курсы, ремонт квартир). В нём реальные данные из Google: адрес или район с ориентиром, часы работы,
«сейчас открыто», рейтинг, удобства (оплата картой, парковка, терраса…), карта. Если Google отдаёт фото
и отзывы, они тоже попадают на сайт (галерея и блок отзывов). Цены в прайсе примерные и так и помечены.

- Шаблоны и тексты: `demo_kinds.py` (тексты AZ/RU, прайс, цвета), вёрстка: `demo_site.py`.
- Перегенерировать все демо: GitHub → Actions → «Поиск клиентов каждый день» → Run workflow →
  галочка «Перегенерировать все демо-сайты». Локально: `python autopilot.py --rebuild 300`.
- Сайт, сделанный вручную, не перезаписывается: у лида в `data/leads.json` стоит `"custom_site": true`.
- Лиды не из Азербайджана отбрасываются (кроме добавленных вручную с личным сообщением `msg`).
