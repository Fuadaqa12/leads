# 🚗 Захват Говсан

Онлайн-игра для Телеграм-группы: мини-приложение + бот. Карта — настоящие улицы Говсан (`public/hovsan.jpg`).

- Машина едет только по улицам, на перекрёстке сворачиваешь пальцем. За машиной тянется след.
- Вернулся на свою землю и замкнул круг — всё внутри стало твоего цвета. Чужую землю тоже можно отжать.
- Лоб в лоб: на своей земле ты поглощаешь чужака, на ничьей машины отскакивают. Переехал чужой след — его хозяин разбился.
- Земля сохраняется навсегда. Топ — у кого больше % района.
- Соло «Гонка»: 3 минуты против ботов, медали 🏅 за 10/20/35/50/70% района. Испытание дня.
- Пират Fuadaqa12 иногда врывается и отжимает дворы. 8 пасхалок (`/eggs`).
- Команды бота: `/arena` `/top` `/me` `/medals` `/eggs` `/announce` (и секретные).

## Как устроено
Node.js-сервер `src/server.js`: раздаёт игру из `public/`, держит онлайн-арену по WebSocket (`src/arena.js`),
принимает вебхук Телеграма (`src/bot.js`). Движок общий для сервера и соло: `public/grid.js` (территории), `public/city.js` (граф улиц), `public/roads.js` (сетка дорог).
База игроков (`src/store.js`) хранится в секретном GitHub Gist (`src/storage.js`), локально в `data/db.json`.

## Хостинг: Render (бесплатно, вход через GitHub)
`render.yaml` в корне репо описывает сервис. В Render: New → Blueprint → репо `leads` → заполнить:
- `BOT_TOKEN` — токен от BotFather;
- `GH_GIST_TOKEN` — GitHub-токен с правом `gist` (для базы).

Вебхук, команды и кнопка «Играть» настраиваются сами при старте. Токены в код не попадают.
Сервер сам пингует себя раз в 10 минут, чтобы бесплатный Render не засыпал.

Кнопка «Играть» прямо в группе: в BotFather → Bot Settings → Configure Mini App → включить и вставить адрес игры,
затем в Render добавить переменную `MINIAPP_SHORT=main`.
